# Audio narration publishing

HIDD articles and case studies can generate one reusable narration file from their published text. The audio is generated by a signed Sanity webhook, uploaded to Sanity as a WAV asset, and shown only while its saved content hash matches the current published copy.

## One-time deployment setup

Add these server-only environment variables locally and in Vercel:

```text
OPENAI_API_KEY=...
SANITY_NARRATION_WEBHOOK_SECRET=...
```

Use a unique webhook secret with at least 32 random characters. Do not prefix either variable with `NEXT_PUBLIC_`.

The existing `SANITY_API_WRITE_TOKEN` must also be available in Vercel because the server uploads the generated file and attaches it to the source document.

## Sanity webhook

In `sanity.io/manage`, open the HIDD project and create a webhook with these settings:

- Name: `Generate HIDD audio narration`
- URL: `https://www.hiddadvisory.com/api/narration/generate`
- Dataset: `production`
- Trigger on: Create and Update
- Filter: `_type in ["post", "caseStudy"] && narrationEnabled == true`
- Projection: `{_id, _type}`
- HTTP method: `POST`
- Include drafts: Off
- Secret: the exact value of `SANITY_NARRATION_WEBHOOK_SECRET`

The endpoint verifies Sanity's signature before doing any work. Repeated webhook deliveries do not regenerate unchanged narration because the endpoint compares the current content hash with the saved hash.

## Editor workflow

1. Open an Insight Article or Case Study in Studio.
2. Enable **Generate Audio Narration**.
3. Choose a voice. Cedar is the default.
4. Optionally add pronunciation guidance for names, locations, abbreviations, or specialist terms.
5. Publish the document.
6. Check the webhook attempt in Sanity Manage. Generation can take a short while for long content.
7. Refresh the public article or case study after generation completes. The player appears below the page metadata.

When the written content, voice, or pronunciation guidance changes, publish again. The website hides an outdated recording until the replacement audio has been generated and saved.

## Public disclosure

The player labels the recording as an AI-generated voice. The written page remains the accessible transcript and continues to be the source of truth.
